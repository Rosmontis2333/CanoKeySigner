交易签名 / Bitcoin

PSBT v0 · v2

支持 P2PKH、P2WPKH、P2SH-P2WPKH，以及标准 P2SH / P2WSH / P2SH-P2WSH 多签。导入 Base64、Hex 或二进制 PSBT v0 / v2，审查全部输入、输出、多签门槛、锁定时间与矿工费。

手动签名 / Solana

legacy · v0 · v1

自动识别已编码 transaction / message、标准 offchain 消息及可阅读文本。可阅读文本将生成 offchain v1 消息。导入交易后，完整展示 signer、账户权限、blockhash 和指令，验证并保留已有签名。v1 展示消息头资源配置，完整消息不超过 1331 字节时可签名，超出时仅供审查。

可选 RPC 读取与模拟
