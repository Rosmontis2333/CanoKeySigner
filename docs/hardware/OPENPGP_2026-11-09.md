# OpenPGP 真机验证记录

测试日期为 2026-11-09，设备为 CanoKey Canary，Admin 原始固件报告为 `3.0.3-0-g30917b92`。测试通过本项目 localhost 页面和 WebUSB 进行，操作者在页面输入 PW1 并按设备策略触摸。

| 现有槽位 | 算法 | 精确签名输入 | 真实结果 |
| --- | --- | --- | --- |
| SIG | Ed25519 | 98 字节固定原始消息 | 64 字节签名，本地 Noble 与独立 Node/OpenSSL 验签通过 |
| AUT | secp256k1 ECDSA | 100 字节固定消息的 SHA-256，32 字节摘要 | 64 字节 r‖s，本地 Noble 与独立 Node/OpenSSL 验签通过 |

SIG 的 UIF 原始值为 `0020`，AUT 为 `0120`，触摸缓存为 0 秒。读取时 PW1 剩余尝试次数为 3。AUT 本次按触摸策略完成。每次签名后，`VERIFY FF 81` 和 `VERIFY FF 82` 均成功，页面报告认证已清除。

原始消息、公钥、设备原始签名和规范化签名均保存在公开证据 JSON。两个样本分别导出后，按相同设备报告合并。证据中包含当前公钥及签名，不含 PIN。[原始公开证据](openpgp-2026-11-09.json)

独立验签使用 Node.js v22.23.1 / OpenSSL 3.5.7，脚本只调用 Node `crypto`，验证设备原始签名与规范化签名，secp256k1 同时核对 SHA-256 输入及 low-S 转换关系，Ed25519 核对精确原始消息。修改消息后两种算法都拒绝验签。[独立验签结果](openpgp-2026-11-09-verification.json)

在项目根目录可以复核。

```sh
node scripts/verify-openpgp-evidence.mjs docs/hardware/openpgp-2026-11-09.json
npm test
npm run build
```
